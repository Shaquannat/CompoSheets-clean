# CompoSheets

CompoSheets is a visual worksheet builder for educators.

Teachers can build printable worksheets by dragging reusable components onto a page instead of formatting documents manually.

## Features (Planned)

- Text
- Questions
- Answer Lines
- Tables
- Checkboxes
- Images
- Shapes
- Multiple Pages
- PDF Export
- Reusable Component Library

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS

## Status

Currently in active development.
